# Additional Instructions

A-01 A code comment must only explain what is not obvious from the code itself. It must not restate the code.

A-02 All written text, including comments, commit messages, pull requests and replies, must use plain English for non-native speakers: common words, short sentences with simple structure, and no metaphors.

A-03 Names of variables, constants, functions, components, types and CSS classes must say what they hold or do, so that the reader does not need to read the code behind them.
